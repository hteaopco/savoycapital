# uploads/ — raw files handed over for a build

Drop-off point for source material that arrives from outside the repo: logos, photography,
PDFs, exports, anything handed over to be used in a build. Files land here as they were
sent, unedited.

**This is not an asset directory.** Nothing in the app should import from here. When a file
is actually used, a processed copy — resized, cropped, converted, renamed to the convention
of wherever it lives — goes to its real home (`public/`, `design/`, a component folder).
The original stays here as the record of what was supplied.

Keep it that way: `design/` is the design source of truth and its contents are
byte-identical to theAPlink's. Loose uploads sitting in it blur that line, which is why
these moved out.

# scoping/archive/ — completed builds, kept as records

Nothing in here is live. Every doc is the stamped record of a build that shipped or a
design that was retired — status, PR pointers, and any tripwires are in its own header.
Docs move out of the live queue so orientation reads and greps stop landing mid-file in
finished or falsified designs: the `archive/` in a grep hit's path is the signal that a
banner at the top of the file cannot give you.

Filenames do not change on the move. Dated records that cite the old
`.claudet/scoping/<file>` path are deliberately not rewritten — follow them here.

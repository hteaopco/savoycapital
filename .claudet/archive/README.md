# archive/ — dated snapshots and resolved records

Nothing in here is live, and nothing in here is maintained. Two kinds of file land here:

- **Dated snapshots** of a working-memory file that got too long to stay useful — named
  with the date they were frozen (e.g. `STATE-2026-08-16.md`). Graduate any still-live
  gotcha out of a snapshot into the right playbook or `DECISIONS.md` the next time you work
  that area; don't leave the only copy in a frozen file.
- **Resolved records** moved out of a live file so its listing stays honest — resolved bugs
  out of `BUGS.md` (e.g. `BUGS-resolved-2026-08.md`), and anything else whose presence in
  the live set would overstate what's open.

Read anything here as history. If it contradicts a live file, the live file wins.

_Empty._
